About this pipeline▾
What it does

Upload a meeting / interview / lecture recording (audio or video). The pipeline transcribes it, separates speakers, converts to Traditional Chinese (configurable), and adds punctuation. You get a readable transcript with timestamps and speaker labels.

Pipeline
StepToolWhere
TranscriptionWhisperX (large-v3 / medium / small)Local AI · $0

Speaker diarizationpyannote.audioLocal AI · $0

Role classificationClaude Haiku 4.5 (5-sample prompt)Anthropic API
Punctuation polishClaude Haiku 4.5 (no rewrites)Anthropic API

Privacy
  • Audio files never leave your machine. Transcription, alignment, diarization, and OpenCC all run locally.
  • Transcribed text is sent to Anthropic API for the last two steps (role classification + punctuation). Set LLM_ENABLED=false to skip them.
  • No telemetry. This project does not phone home.
