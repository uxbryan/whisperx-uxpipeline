      Step 1 — save the .env above.
      In Terminal:
    

    
cd /path/to/whisperx-uxpipeline

# Option A: after clicking the Copy button above
pbpaste > .env

# Option B: if you used Download env.txt
mv ~/Downloads/env.txt .env

cat .env   # verify content is correct


    

      Step 2 — install dependencies + verify.
    

    
python3.13 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python scripts/check_setup.py    # ← run this!

    

    


    

      Step 3 — launch the server.
    

    
.venv/bin/python web/server.py
